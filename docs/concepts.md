# Concepts

**Guessability** depends on which passwords an attacker tries early. A long keyboard pattern can be easy to guess. Length, uniqueness and unpredictability are more useful than trying to maximize a simple character-group count.

**Character groups** are properties of individual characters. Python's Unicode-aware string methods recognize lowercase, uppercase and decimal characters beyond ASCII.

**Pure functions** return results from their inputs without changing external state. Keeping the rating function separate makes it possible to verify exact behavior without typing into a terminal.
